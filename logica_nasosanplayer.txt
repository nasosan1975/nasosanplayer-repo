SCOPO
App musicale retro ispirata alle cassette a nastro. Riproduce file
audio locali da cartelle Android. Nessun dato inviato online.
Solo Android. Tema scuro fisso.


==============================================================
1. STACK TECNICO
==============================================================

- React Native + Expo (Expo Router, file-based navigation)
- Playback audio: Media3/ExoPlayer tramite NasoSanPlaybackService
- Player setup tramite NasoSanPlayer.setup({}) una sola volta (flag rtpReady)
- Accesso file: Android Storage Access Framework (SAF) via expo-file-system/legacy
- SVG: react-native-svg
- Persistenza: AsyncStorage + file JSON scritto nella cartella musicale
- Native modules custom iniettati via Expo config plugins (plugin JS che
  scrivono codice Kotlin a build-time):
    * withMedia3Player.js  — NasoSanPlaybackService (Media3), NasoSanPlayerModule,
                             TrackCacheModule, CarModeModule,
                             SpeechnotesWidgetModule, SpeechnotesWidgetViewManager
    * withVolumeAnalyzer.js — analisi RMS e gain via MediaCodec + LoudnessEnhancer
    * withWmaPlayer.js     — stub vuoto (WMA rimosso)
    * withAbiFilter.js     — solo arm64-v8a
    * withDisableNewArch.js — newArchEnabled: false

14. LOGICA PLAYER (PlayerContext.tsx)
==============================================================

--- INIZIALIZZAZIONE ---
All'avvio: carica da AsyncStorage cartella, settings (shuffle/fav).
Se cartella trovata: scanFolder(uri) per caricare le tracce.
ensureRtpSetup(): configura NasoSanPlayer una sola volta.

--- SCANSIONE CARTELLA ---
SAF.readDirectoryAsync(uri) → filtra con regex AUDIO_EXTS:
  /\.(mp3|flac|ogg|aac|m4a|wav|opus)$/i
File ordinati alfabeticamente.
Parsing nome file: "Artista - Titolo.ext" → artist + title separati.
  Se nessun " - " → tutto come titolo, artista vuoto.
ID3 tags letti per le nuove tracce (non già in cache).
Posizione precedente ripristinata dalla cache.
Shuffle order ripristinato se valido (stessi file).
Gain (normalizzazione) ripristinato se presente.

--- STRUTTURA TRACK ---
{ id, filename, uri, title, artist, positionMs, favorite }
id: indice numerico progressivo (0-based).

--- LATO A / LATO B ---
sideACount = ceil(tracks.length / 2)
Lato A: tracce 0 … sideACount-1
Lato B: tracce sideACount … end
currentSide: "A" o "B" in base a currentIndexInActive
sideProgress: 0.0→1.0, posizione dentro il lato corrente
  = (indexInSide + positionMs/durationMs) / countInSide

--- LISTA ATTIVA ---
activeList = tracks filtrati per favoriti (se favoritesMode) e/o
             riordinati per shuffle (se shuffleMode).
currentIndexInActive = posizione corrente in activeList.

--- PLAYBACK ---
play():   setup queue su NasoSanPlayer, seek alla posizione salvata, play
pause():  pause, salva posizione
stop():   stop, posizione → 0, salva su file
next():   traccia successiva in activeList (circolare), play
prev():   se posizione > 3 secondi → restart; altrimenti traccia precedente
FF/RW:   startFF/startRW avviano setInterval che fanno seekTo ripetutamente (+/-2s)
          stopFF/stopRW fermano l'intervallo

Stop countdown: schedulato in secondi, decrementa ogni secondo.
  A zero: stop(). Tocco cassetta durante countdown → annulla + play.

pauseForScreen() / resumeAfterScreen(): pausa per modal/settings, riprende se era in play.

--- SALVATAGGIO DATI ---
File "nasosanplayer_data.json" scritto nella cartella musicale (SAF).
AsyncStorage come cache rapida (keys: @nasosan_data_*, @nasosan_folder, ecc.).
Salvataggio automatico: su cambio traccia, stop, modifica, shuffle, favoriti.

15. NORMALIZZAZIONE VOLUME (VolumeAnalyzer)
==============================================================

Modulo nativo Android (Kotlin, iniettato da withVolumeAnalyzer.js):
  - Analisi RMS via MediaCodec (decodifica PCM raw)
  - Gain applicato via LoudnessEnhancer sull'audioSessionId del player Media3

Algoritmo analisi (analyzeRMS):
  1. Seek: se durata > 30s → seek a 30s; altrimenti a 0s.
     Se campione a 30s è silenzio (n==0 dopo finestra) → retry a 0s.
  2. Finestra analisi: 5 secondi × sampleRate × channels samples.
  3. Filtra campioni silenzio: |s| > 0.001 (ignora silenzio puro).
  4. RMS = sqrt(sumSq / n), convertito in dBFS = 20*log10(rms).
  5. Se n==0 → ritorna -60dB.

Calcolo gain per cassetta:
  maxRms = valore più alto tra tutte le tracce.
  gain(traccia) = max(0, maxRms - rms(traccia)) in dB.
  Applicato con LoudnessEnhancer(sessionId).setTargetGain(gainDb * 100).
  Range: 0–2000 mB (0–20 dB). Unità Android: 100 mB = 1 dB.

Comportamento LoudnessEnhancer:
  - Istanza creata UNA SOLA VOLTA per sessione audio (non ricreata ad ogni traccia).
  - Cambio traccia: aggiorna solo targetGain e enabled sull'istanza esistente.
  - gain <= 0.1 dB → enabled = false (nessun boost).
  - gain > 0.1 dB → setTargetGain + enabled = true.
  - Evita race condition: sessionId 0 non distrugge l'enhancer esistente.

Progresso UI: durante analisi il bottone NORM mostra numero traccia corrente (2 cifre).
RMS calcolati salvati in AsyncStorage (@nasosan_rms_*) per evitare ricalcoli.
Gain salvati in AsyncStorage e nel file JSON della cartella.

16. CAR MODE / ANDROID AUTO
==============================================================

--- RILEVAMENTO CAR MODE ---
Modulo nativo Android CarModeModule (withMedia3Player.js).
Usa AudioDeviceCallback per rilevare connessione/disconnessione USB audio:
  - onAudioDevicesAdded: device TYPE_USB_* → emette nasosan_car_enter
  - onAudioDevicesRemoved: device TYPE_USB_* → emette nasosan_car_exit
Nessun lock orientamento. Nessun retry: callback nativa è affidabile.

Lato React Native (index.tsx):
  - isCarMode state: inizializzato da CarModeModule.isInCarMode() al mount
  - DeviceEventEmitter.addListener("nasosan_car_enter") → setIsCarMode(true)
  - DeviceEventEmitter.addListener("nasosan_car_exit") → setIsCarMode(false) + pause()

--- ANDROID AUTO (NasoSanPlaybackService) ---
NasoSanPlaybackService estende MediaLibraryService.
Registrato nel manifest con intent-filter per MediaLibraryService e MediaBrowserService.

onConnect (controller AA):
  1. Avvia auto-play se mediaItemCount > 0 (delay 1000ms).
  2. Se widget Speechnotes abilitato (widget ID in SharedPrefs nasosan_prefs):
     → lancia MainActivity in foreground (FLAG_ACTIVITY_NEW_TASK |
       FLAG_ACTIVITY_REORDER_TO_FRONT, delay 1500ms).
     Funziona anche se app era chiusa completamente.
  3. Se widget NON abilitato → nessun cambio (background play come prima).

onDisconnected (controller AA):
  → player.pause() sul main thread.

--- WIDGET SPEECHNOTES + CAR MODE ---
Il widget Speechnotes nel player è visibile SOLO se:
  speechnoteEnabled == true  (impostazione utente)
  AND isCarMode == true      (cavo AA connesso)
Se manca uno dei due → widget nascosto, comportamento normale invariato.

17. WIDGET SPEECHNOTES (SpeechnotesWidgetModule + ViewManager)
==============================================================

Integrazione widget Android AppWidgetHost per Speechnotes (co.speechnotes.speechnotes).
Iniettato via withMedia3Player.js come moduli Kotlin.

--- RILEVAMENTO APP ---
Manifest Android include <queries><package android:name="co.speechnotes.speechnotes"/>
</queries> per visibilità su Android API 30+.
isInstalled(): getPackageInfo(PKG, 0) → true/false.

--- SELEZIONE WIDGET ---
Da AppWidgetManager.getInstalledProviders() filtrati per package Speechnotes:
  → minByOrNull { minWidth * minHeight }  (prende il più piccolo = 1x1)
  → fallback su firstOrNull() se minByOrNull fallisce
  → errore se lista vuota.

--- BIND WIDGET ---
requestBind():
  1. Se ID già in SharedPrefs → resolve con ID esistente.
  2. bindAppWidgetIdIfAllowed() → se ok → salva ID, resolve.
  3. Altrimenti → startActivityForResult(ACTION_APPWIDGET_BIND) →
     onActivityResult → salva ID se RESULT_OK.
Widget ID salvato in SharedPrefs "nasosan_prefs" chiave "speechnotes_widget_id".
Richiede permesso BIND_APPWIDGET nel manifest.

--- RENDERING (SpeechnotesWidgetViewManager) ---
FrameLayout nativo che ospita AppWidgetHostView.
onAfterUpdateTransaction: carica il widget se non ancora presente.
onInterceptTouchEvent ACTION_DOWN → emette evento "onWidgetTap" a React Native.

--- STATO IN ASYNCSTORAGE ---
"speechnote_enabled": "true" / "false"
Letto con useFocusEffect in index.tsx (aggiornato ad ogni focus).
